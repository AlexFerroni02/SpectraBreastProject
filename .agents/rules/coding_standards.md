# Coding Standards & Guidelines

1. **Language**: All source code, docstrings, and in-code comments must be strictly written in **English**.
2. **Notebooks**: All Jupyter notebook markdown cells, code cells, comments, and labels must be written in **English**.
3. **Spectral Naming**: Use **HW** (High-Wavenumber) when referring to the full high-wavenumber Raman region (~2400-4000 cm⁻¹), and use **CH** specifically when referring to the aliphatic C-H stretching band (~2800-3050 cm⁻¹).
